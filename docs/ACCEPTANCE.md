# Packaged Runtime Acceptance

Before enabling the console-login handoff, start the staged packaged runtime
under X as the normal user and verify all of the following manually:

- FORGE opens `~/FORGE-OS` in place.
- A file can be opened, edited, saved, and read back.
- A new integrated terminal starts in `~/FORGE-OS`.
- `whoami` reports `North3rnLight3r`; `pwd` reports the workspace.
- `codex --version` runs from the integrated terminal.
- After closing and restarting FORGE, the workspace reopens and its
  `.forge/metadata.sqlite` state remains available.
- `echo "$DISPLAY"` prints a valid X display.
- `echo "$XDG_RUNTIME_DIR"` identifies the current user's runtime directory.
- `echo "$DBUS_SESSION_BUS_ADDRESS"` identifies the user bus.
- `xdg-open https://github.com` opens the default browser.
- A graphical application launched from the integrated terminal appears.
- The Applications surface lists installed launchable desktop entries and can
  launch one without invoking a shell.
- The clock follows the current locale/timezone and System Overview is accurate.
- Restarting FORGE preserves workspace state.

Record the observation time, executable path, SHA-256, and result in
`BUILD_STATE.md`. Only after every item passes, create `build/acceptance.env`
with exactly:

```sh
PACKAGED_RUNTIME_ACCEPTED=yes
```

Then `scripts/enable-autostart.sh` may install the TTY1 handoff. This marker is
evidence of a human observation and must never be generated by an unattended
test.

## Graphical-login acceptance

After the files are staged with `scripts/install-graphical-login.sh`, test the
FORGE entry without enabling persistent startup. Verify the greeter uses PAM,
the FORGE session opens, logging out returns safely, `Ctrl+Alt+F2` remains
available, and `scripts/rollback-graphical-login.sh` restores the baseline.

Only the human may then create `build/graphical-login-acceptance.env` containing:

```sh
GRAPHICAL_LOGIN_ACCEPTED=yes
```

`scripts/enable-graphical-login.sh` refuses to enable greetd without it. No
script reboots the system or enables automatic login.
