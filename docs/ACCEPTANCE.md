# Packaged Runtime Acceptance

Before enabling the console-login handoff, start the staged packaged runtime
under X as the normal user and verify all of the following manually:

- FORGE opens `~/FORGE-OS` in place.
- A file can be opened, edited, saved, and read back.
- A new integrated terminal starts in `~/FORGE-OS`.
- `whoami` reports `North3rnLight3r`; `pwd` reports the workspace.
- `codex --version` runs from the integrated terminal.
- After closing and restarting FORGE, the workspace reopens and its
  `.forge/metadata.sqlite` state remains available.

Record the observation time, executable path, SHA-256, and result in
`BUILD_STATE.md`. Only after every item passes, create `build/acceptance.env`
with exactly:

```sh
PACKAGED_RUNTIME_ACCEPTED=yes
```

Then `scripts/enable-autostart.sh` may install the TTY1 handoff. This marker is
evidence of a human observation and must never be generated by an unattended
test.
