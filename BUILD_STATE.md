# Current build state

Updated 2026-08-11 after the boot/session/package architecture repair.

Repository architecture now targets graphical greetd login by default, direct explicit Xorg session handoff, content-addressed runtime installation, correct Electron sandbox permissions, tty2 recovery, and strict production verification. `build/latest.env` is machine-local and ignored.

The exact observed installed runtime identity and service state are regenerated by `scripts/build-forge.sh`, `scripts/install-forge-os.sh`, and `tests/verify.sh`; they are intentionally not frozen in tracked host-specific paths here.

Physical reboot/login, application launch, logout, and integrated-terminal validation remain human-observed release checks and must not be inferred from repository tests.
